# Courier & Logistics Template

**Maturity: scaffolded — not a released product.**

A responsive, self-contained marketing website starter for courier, freight and e-commerce logistics businesses. It includes a local demo shipment-tracking interaction, accessible navigation, service cards, process explanation, network illustration and editable contact placeholders.

## Run

- `pnpm --filter @web-temify/courier-logistics-template validate`
- `pnpm --filter @web-temify/courier-logistics-template test`
- `pnpm --filter @web-temify/courier-logistics-template build`

The build copies the static site assets to `dist/`. There are no runtime dependencies or external assets in this scaffold.

## Before customer use

- Replace the Northstar Logistics demo brand and all placeholder contact details.
- Replace illustrative copy with verified service coverage, operational claims, privacy and legal information.
- Connect shipment tracking only to an authorized backend and real carrier/provider data after designing authentication, rate limiting, privacy and data-retention controls.
- Review content rights, license, security, browser support and accessibility before any release.
- Do not mark this product released based on a successful static build. Its manifest has no source commit, rights are not verified, and security review has not started.

## Scope

This is a front-end template, not a shipping management backend, carrier integration, payment flow, dispatch optimizer, or production tracking service.
